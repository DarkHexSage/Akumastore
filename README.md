# Tienda Anime CR

Catálogo de productos anime con pedidos por WhatsApp.

## Setup

1. Poné tus imágenes en `public/images/products/`
2. Cambiá el número de WhatsApp en `app/page.tsx` (línea 5)
3. Deploy en Vercel
